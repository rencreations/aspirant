# History

- **10-16** Design spec, canon rules and open questions (`docs/design/`, `docs/OPEN-QUESTIONS.md`), the content layer (`src/content`), and the media pipeline (`scripts/assets`). The owner was asleep during the first build, so the open questions carry the defaults that were chosen.

## 2026-10-30

- **"The page is ALWAYS a normal page with no animation" on aspirant.cc** (`7c8e65e`). Timeline of a first visit on a 1 Mbit phone connection showed the cause: the boot script dropped its blank cover after **9 seconds**, and the server renders the full site underneath, so until the scripts arrived the visitor saw the plain text of the page with no animation (about 16 s at 1 Mbit); the loading screen only appeared after that; items gave up after 12 s; the loader gave up at 60 s; data saving turned off the 3D opening. Fixes: the cover now carries the wordmark, a sweeping line and notes, and stays until the scripts start; the loader waits longer and tells the visitor the connection is slow (15 s), offers "Enter now" at 45 s and stops at 240 s; items wait 60 s; a page change 90 s; data saving no longer disables the opening scene. ## 2026-11-03: the new story, as a visual read

The owner replaced the old novel with a new one ("Aspirant", `D:\ren\aspirant\story\main.md`: a prologue and 48 chapters, about 34,000 words, written in short plain sentences from the official sources only) and asked for the story page to be a **high-visual read**: images, comic panels cropped from the official comics, frames and clips from the official films (the footage folders), voice lines and music in the right place of each scene, "lots of design and creativity" so the visitor is entertained and can picture what happens. The old story was to be removed completely, "starting from the chapter preview, the short description, the whole stories".

- **This reversed the owner's decision of 1 Nov** (the reader is plain text on one plain colour, no image, scene or sound). The request was explicit, so the rule in `CLAUDE.md` was rewritten and the old reader's scenes stay removed: the new pictures are set in the text, not behind it.
- **One chapter to a page** (49 pages and an end page) instead of twelve Parts, so each page loads only its own pictures. The old `/story/part-NN` addresses redirect.
- **A pipeline instead of hand-placed pictures** (`scripts/story/`): the novel is parsed, a hand-written visual script per chapter says which official picture, panel or clip goes after which paragraph, and `build.py` checks it against the text and the files, makes the media and writes the data. Eight curators (helper sessions) chose the pictures for blocks of chapters with the looking tools, from the source log that ties each scene of the book to an official file; a storyboard sheet per chapter (`tools/storyboard.py`) is how a chapter's pictures are checked against its text.
- **Voice lines** (88) come from the markers in the novel and play from a small player under the line. **Music** is the site's seven existing tracks, one per stretch of the story, through the nav's record.
- **Spoilers.** The landing shows a card picture for every chapter; a picture that would give something away is blurred and dark ("Sealed") until the visitor has reached that chapter.
- **The old story's leftovers.** The About page, the home contrast and the character pages were written from the old story and still link to old chapter ids. A map (`features/story/legacy-map.json`) sends each to the nearest chapter, and the old back matter is kept as a frozen data file for About. Those pages need their own pass.
- Found along the way: Windows treats `blocks.tsx` and `Blocks.tsx` as one file (the old file was untracked in git first); an `em` length in a custom property resolves where it is used, so the text measure is now in units of the reading size; a bash heredoc with quotes broke while writing a test file (the editor tool does not).
