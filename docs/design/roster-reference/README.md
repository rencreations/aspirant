# Roster reference

The owner's reference for the `/character` opening and look: `transitions.mov`, a 9.5 s, 1920x1080, 60 fps screen recording of a game's collection page. The audio track is silent. It is the target of `scripts/roster-intro/compare.mjs` (the default `--ref`).

| File                                           | What                                                               |
| ---------------------------------------------- | ------------------------------------------------------------------ |
| `transitions.mov`                              | The recording                                                      |
| `sheet0.jpg` to `sheet3.jpg`                   | Contact sheets of the opening, 0.6 s to 4.7 s                      |
| `dsheet0.jpg` to `dsheet3.jpg`                 | Denser contact sheets of the same stretch                          |
| `full_5.3.jpg`, `full_7.0.jpg`, `full_9.3.jpg` | Full-size frames of the finished page and its idle pulse           |
| `welcomes.jpg`                                 | Each character's welcome animation, as used in the burst of panels |

The second-by-second reading of the recording is in [../roster-intro.md](../roster-intro.md). The game's own interface in the recording (top bar, benefits bar) is not copied by the site.
