# Collection landing: the reference

The owner asked (4 Nov 2026) for `/collection` to open like <https://www.shopify.com/editions>. These frames were recorded from that page in Chrome at 1440x900 and 390x844 (2x) on 4 Nov 2026. They are for looking at. Nothing of the reference's code, art or wording is used: the site rebuilds the structure and the motion with its own pictures, type and words.

## How the site uses it

Design and rules: `docs/superpowers/specs/2026-11-04-collection-library-design.md`. In short: ten covers, two shelves of five, in the order Arts, Films, Music, Voicelines, Fanart (shelf one) and Comic, Lore, Design, Animation, Others (shelf two). Open hands off to the logo page transition. The blur is drawn inside the WebGL scene (the site bans CSS `filter` and `backdrop-filter` over live pictures).
